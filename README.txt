SMART ATTENDANCE — โรงเรียนแสวงหาวิทยาคม

เปิดใช้ทันที
1) แตก ZIP
2) เปิด index.html
3) ไปเมนูนักเรียน แล้วโหลดข้อมูลตัวอย่างหรือเพิ่มข้อมูลจริง
4) ไปเมนูแตะบัตร แล้วทดสอบ CARD001

ระบบที่มีในรุ่นนี้
- Dashboard
- RFID/NFC UID attendance
- เพิ่ม/แก้ไข/ลบนักเรียน
- ผูก UID บัตร
- มา/สาย/ลา/ขาด
- ป้องกันแตะซ้ำ
- รายงานรายวันและรายห้อง
- CSV import/export
- Kiosk-friendly attendance screen
- ตั้งเวลาเรียนและเวลาสาย
- สำรองข้อมูล JSON / กู้คืน
- Responsive สำหรับมือถือ/iPad/คอม

การต่อ RFID
เครื่องอ่านแบบ USB HID/Keyboard Wedge สามารถพิมพ์ UID ลงช่องแตะบัตร แล้วกด Enter

ข้อจำกัดของ standalone
ข้อมูลเก็บใน LocalStorage ของเบราว์เซอร์ จึงเหมาะกับเครื่องเดียว/เดโม หากใช้จริงหลายเครื่อง
ควรย้าย storage ไปฐานข้อมูลกลางและมี server authentication/HTTPS ก่อนเก็บข้อมูลนักเรียนจริง
